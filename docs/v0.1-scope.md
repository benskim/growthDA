# v0.1 Scope — 최단기간 실행 버전

> 이 문서는 `docs/prd.md`에 정의된 전체 비전(Phase 1~8) 중, **Phase 1~5를 얇게 구현한 v0.1 실행 범위**만 다룬다.
> 비전 자체를 축소하는 것이 아니라, 첫 완성 버전의 범위를 최소화하는 것이 목적이다.

---

## v0.1 목표

> 하나의 Ecommerce 데이터셋으로 **Event → Metric → State → Journey(Funnel/Retention)**까지 파이프라인이 동작하고, 결과를 시각화로 확인할 수 있다.

---

## v0.1에 포함되는 것

- Phase 1: Data Foundation (얇게)
- Phase 2: Behavior & Event Modeling (얇게)
- Phase 3: Metric Layer (5개 이내 Metric, 하드코딩)
- Phase 4: State Engine (5~6단계, if-else 하드코딩, DSL 없음)
- Phase 5: Journey Analytics (Funnel + Retention만)
- 시각화 (Sankey 1개, Funnel 차트 1개)

## v0.1에서 제외되는 것

- State Engine의 DSL/Rule 외부화 → 하드코딩으로 대체 (향후 확장 시 도입)
- Phase 6 Driver Analysis → 전부 제외
- Phase 7 Causal Validation → 전부 제외
- Phase 8 Experiment Recommendation → 전부 제외
- Real-time, multi-user, auth 등 → PRD 원래 계획대로 계속 제외

## v0.1 완료 기준 (Definition of Done)

- 하나의 데이터셋에 대해 Step 1~5가 오류 없이 end-to-end로 실행된다.
- State Table의 각 사용자가 정확히 하나의 State에 배정되어 있다.
- Funnel과 Retention 결과가 시각화로 확인 가능하다.
- 코드/문서 어디에도 Driver, Causal, Experiment 관련 로직이 없다 (범위 침범 방지).
